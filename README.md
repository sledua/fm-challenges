# fm-challenges

Колекція фронтенд-челенджів, зроблена для практики та експериментів — у стилі Kevin Powell: просто, практично, з підказками для візуалізації та вдосконалення CSS/HTML/JS.

Коротко:
- Робиш, тестуєш, вчишся.
- Кожен челендж — окрема папка з README зі «що робити» і «що спробувати».
- Запуск через Live Server або npm-скрипти.

## Як запускати
1. В корені:
   ```bash
   npm install
   ```
2. Запуск конкретного челенджу:
   ```bash
   npm run dev:01-landing-page   # приклад
   ```
   Або відкрий папку в VS Code і натисни Go Live.

## Структура (рекомендована)
```
fm-huddle-landing-page-with-alternating-feature-blocks/
TEMPLATE-README.md
README.md
package.json
```

## Підхід (Kevin Powell style)
- Починай з простої вёрстки — потім додай деталі.
- Часті маленькі коміти. Коментарі в CSS про думки/рішення.
- Експериментуй із кольорами, layout, flex/grid — дивись результат в живу.

## З чого почати
1. Відкрий папку `01-landing-page`.
2. Пограй з CSS змінюючи перемінні/фони.
3. Додай задачу в README кожного челенджу: "Try this" — і закомить.
